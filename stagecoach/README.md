# The Stagecoach Group — home page (motion build)

Static page, no build step. Open `index.html` through any local server.

The page is built around the locked cover motion (Brand Source of Truth A8):

1. **Opening** — name → point + single ring → S draws → name settles. Once per visit, skippable (click, key, scroll), off under reduced motion.
2. **Hero** — the S is a window onto the Capitol at night; scrolling travels through the stroke until the city fills the screen and the promise appears.
3. **How a call works** — the symbol builds itself in three scroll stages: point = Intake, ring of options = Triage, S stroke = Response.
4. **Journey** — the S draws again beside "A protected journey, drawn in one letter."

Open items carried over from v3: photography is hotlinked from stagecoachmedical.com (rights and originals to request), client names need display permission, Request care is an email link until a form destination is confirmed, licensing wording to confirm.
